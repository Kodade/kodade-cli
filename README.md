# Ködade CLI

A lightweight terminal workspace for the agent CLIs you already use. Workspaces,
tabs, and panes with agent-state awareness — mouse works, keybindings work,
sessions persist. The terminal-native companion to
[Ködade](https://github.com/Kodade/kodade).
